# 🔍 Simple Vulnerability Scanner (Python)

A beginner-friendly cybersecurity project that scans common ports on a target system to identify potential vulnerabilities.

---

## 📌 Project Description

This tool checks whether commonly used ports are **open or closed** on a given IP address or domain. Open ports may indicate potential security risks if not properly secured.

---

## 🚀 Features

* Scans multiple common ports
* Identifies open and closed ports
* Fast and simple command-line interface
* Beginner-friendly cybersecurity project

---

## 🛠 Technologies Used

* Python
* Socket Programming

---

## ▶️ How to Run

1. Install Python (if not already installed)
2. Clone this repository:

   ```bash
   git clone https://github.com/your-username/vulnerability-scanner.git
   ```
3. Go to the project folder:

   ```bash
   cd vulnerability-scanner
   ```
4. Run the script:

   ```bash
   python scanner.py
   ```
